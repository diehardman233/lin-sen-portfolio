01 / 主题方向

📋 主题与角色方向

先确定赛季主题与角色品级，再继续补参考图和 Prompt；下方主题列表会常驻显示，刷新后可以直接看到变化。

下方 AI脑洞推荐 与 经典主题 提供通用演示主题；如果暂时不贴参考图，可以直接从这里生成 Prompt。
🖼️ 可选：贴参考图 不贴也可以，直接从上一步生成 Prompt
02 / 参考图输入

🖼️ 参考图与局部描述

文生图模式下可选上传灵感图；图生图模式下建议至少上传 1 张参考图，并明确说明希望保留的轮廓、配色或局部细节。

图生图建议：可以把脸、发型、服装、配色分别放在不同编号里，后续 Prompt 会自动把这些引用写进去。

点击编号标签插入引用，例如："参考 ① 的帽子造型 + ③ 的配色方案"

03 / Prompt 工作区

✨ Prompt 生成与微调

系统会结合主题、品级和参考图描述生成结构化 Prompt；你可以继续手动微调，再把结果直接送到下方生图区。

翻译通道：基础翻译

可直接输入中文补词，系统会实时逐项翻译成英文，并在生成时一起拼进 MJ Prompt。已接入混元优先翻译，未配置时会自动降级。

🔤 实时翻译设置（推荐混元）
未配置 · 已配置时优先走混元实时中译英；未配置时自动降级为基础翻译
